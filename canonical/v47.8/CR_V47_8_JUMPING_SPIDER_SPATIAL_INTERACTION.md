## Gap found

The v47.7 map specifies the pipe/cavern echo model and four existing free-space units, but does not name or define Jumping Spider. This CR records the missing function without rewriting the parent package or merging it with the web-interrelation function.

## Two distinct operations

| Function | Input relationship | Operation | Output |
|---|---|---|---|
| **Web Spider — direct interrelation** | Events/data attached to a connected web of relations | Let background noise pass; a qualifying event couples into the web, reverberates through its related edges, and calls for attention | Event plus its direct relation/evidence trace |
| **Jumping Spider — spatial approach** | A spatial map and a candidate surfaced by authorized analysis | Select a candidate location, compute a reachable route through mapped space, and move the *modelled observer* to an observation point for a new look | Candidate, route, approach point, observations, and complete return trace |

The web operation detects and propagates relational signal. Jumping Spider actively changes observation position in space. Neither is a compression stage; full source/result return and provenance are retained. They may exchange findings, but neither substitutes for the other's operation.

## Interlock with the current pipe/cavern model

- The non-sight pipe/cavern mapping may supply spatial constraints and echo-derived candidate locations to Jumping Spider **only when those values are present in a validated input record**. Illustrative acoustic traces and unmeasured labels remain unqualified.
- The existing four free-space cardinal units remain part of the 64-unit inventory and report to `C/C1-Open Space`; this CR adds no units and does not assign those units as Jumping Spider actuators.
- A route computation is an analytical/modelled observation step. No external movement, collection, access, or actuation is implied.
- Object selection and route output remain scoped to the supplied analysis domain. Any real-person assessment, external collection, or action requires separate explicit authorization through the Human Gate; no autonomous target classification or action is introduced.
- Preserve the original input, candidate identity, map/version, route, timestamps, uncertainty, and full returned observations. Do not discard the source or reduce the returned evidence.
