The implementation must explicitly incorporate these compatibility revisions:

- **R1 — Observation / qualification boundary:** record encounter before qualification where necessary, but prohibit analytical standing before qualification.
- **R2 — Box / Null boundary:** permit pre-existing object-relative Box geometry without converting qualified Null into mandatory Boxing.
- **R3 — External analytical warrant / execution boundary:** permit native external-bearing analysis and call selection without representing analytical warrant as execution permission.
- **R4 — Sensor / source / evidence separation:** preserve sensor execution, source identity, returned observation, attribution, evidence, and standing as distinct states.
- **R5 — Public representation attribution:** require earned attribution before a candidate enters an object-bound public representation surface.
- **R6 — Dependency-bounded correction:** localize revalidation to materially dependent standing; prohibit global recollapse by default.
- **R7 — Osprey access state separation:** preserve AVAILABLE / ELIGIBLE / EXERCISED and CALL / DO NOT CALL / UNRESOLVED without collapse.
- **R8 — Access inheritance boundary:** preserve orientation and route history; prohibit inheritance of prior maneuver warrant.
- **R9 — Current-operation ambiguity:** do not encode turn boundary, wording equality, object identity, or prior route as a complete operation-identity rule.
- **R10 — Motion / non-motion symmetry:** treat over-launch and under-launch as defects; treat justified stillness as an affirmative analytical result.
- **R11 — Osprey economy / maneuver breadth:** preserve maximum available maneuver space while minimizing exercised motion. Do not reduce capability to enforce economy.
- **R12 — Temporal/source semantic compatibility:** a returned public value must not overwrite a governed value merely because it is newer or differs. Establish semantic and temporal comparability first.
- **R13 — Correction / validation separation:** a candidate correction must not become validated truth by first contact. Independent recheck is required where the operation claims validation.
- **R14 — Originating-data preservation:** manipulation, correction, reorientation, and external actuality pressure operate on governed working standing without erasing originating data.
