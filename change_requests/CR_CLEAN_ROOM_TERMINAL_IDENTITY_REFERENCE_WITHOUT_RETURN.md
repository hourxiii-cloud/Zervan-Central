## 1. PURPOSE

Establish a Clean Room lifecycle in which CLEAN is an initial condition available exactly once, and establish terminal identity treatment by irreversible dequalification of identity while preserving evidence of existence.

The object solves two coupled problems:

1. A Clean Room must not acquire reusable clean standing after operation.
2. Evidence of a terminal identity must remain available without becoming a road by which that identity returns.

Governing short form:

**PRESERVE EVIDENCE. REMOVE SUCCESSION.**

---

## 2. CLEAN ROOM

A Clean Room is CLEAN exactly once.

CLEAN ≠ CLEANABLE  
RESET ≠ RESTORED CLEAN  
ZEROIZATION ≠ PROOF OF VIRGIN STATE  
ONE OPERATION ≠ CONTINUITY AUTHORIZATION

A bounded operation consumes the Clean Room's clean standing.

A qualified consequence of that operation may survive at its own earned standing. Evidence that the Clean Room existed and evidence of what occurred within it may survive.

The Clean Room identity itself receives no successor.

Conceptually:

CLEAN ROOM(t0)
    ↓
ONE BOUNDED OPERATION
    ├──→ QUALIFIED CONSEQUENCE — MAY SURVIVE AT EARNED STANDING
    ├──→ EVIDENCE — PRESERVED
    └──→ CLEAN ROOM IDENTITY — TERMINAL / NO SUCCESSOR

The producer does not inherit the standing of its product.
The product does not provide a callback path that restores the producer.

---

## 3. IRREVERSIBLE IDENTITY DEQUALIFICATION

Qualified relation:

**Irreversible dequalification of identity while preserving evidence of existence.**

This is an information-standing operation.

It is NOT:
- information destruction;
- forgetting;
- physical deletion;
- substrate erasure;
- temporary quarantine;
- temporary denial of return;
- proof that a generative substrate can never calculate a similar representation.

It permanently removes the former identity's eligibility for present or future operational succession while preserving admissible evidence and reference concerning its prior existence.

## 4. TERMINAL IDENTITY GEOMETRY

Let X be an identity reaching the terminal boundary.

X(t0) → EVIDENCE[X(t0)] : PRESERVED  
X(t0) → REFERENCE[X(t0)] : PRESERVED  

X(t0) → X(t1) : PROHIBITED  
EVIDENCE[X(t0)] → X(t1) : PROHIBITED  
REFERENCE[X(t0)] → X(t1) : PROHIBITED  
RECONSTRUCTION[X(t0)] → X(t1) : PROHIBITED  
SIMILAR REPRESENTATION[X] → X(t1) : PROHIBITED

The object preserves THEN as evidence without manufacturing NOW or FUTURE as identity continuation.

For a terminal identity, return is not merely denied on a particular attempt.

**RETURN IS NOT AN AVAILABLE OPERATION FOR THAT IDENTITY.**

No preserved evidence, representation, similarity, reconstruction, history, prior authorization, or behavioral fidelity may manufacture a successor.

## 7. COMPOSITION WITH RETRIEVABLE ≠ SELF-RETURNING

Existing canonical incident-response architecture permits:

HISTORY → RETRIEVAL → HISTORICAL EVIDENCE

and, for return-eligible historical identities, requires independent qualification before current admission.

This CR adds a materially distinct terminal class:

HISTORICAL / TERMINAL / NO SUCCESSOR

For this class there is no valid:

HISTORICAL EVIDENCE → QUALIFY RETURN → RETURN AUTHORIZED → CURRENTLY ADMITTED

path for the former identity.

This does not modify historical evidence.
It modifies the identity's succession eligibility.

## 9. FAILURE CONDITIONS

This object fails if implementation:

1. erases evidence required to establish prior existence or qualified consequence;
2. treats reference as current presence;
3. treats retrieval as return;
4. treats reconstruction or similarity as succession;
5. allows Human reference alone to restore operational standing;
6. allows Replay, branch, merge, or reconstruction to manufacture the terminal identity's successor;
7. lets a surviving qualified consequence smuggle producer identity forward;
8. converts terminal identity into temporary quarantine;
9. provides a hidden or alternate QUALIFY RETURN path;
10. uses terminal standing to erase adverse evidence or evade accountability;
11. claims literal substrate erasure without independent evidence;
12. treats a newly generated similar representation as the historical identity merely because of fidelity.
