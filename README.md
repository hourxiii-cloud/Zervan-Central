# Zervan

Zervan is a governed analytical ecology for evidence, provenance,
relational analysis, verification, and human-gated decisions.

## Release authority

This README is orientation only. It does not declare a release
version, implementation identity, canonical standing, or initiation path.

`VERSION.json` is the governing release identity and path selector.
`VERSION` and `VERSION_AUTHORITY.md` must be checked for consistency
with the active release contract.

## Initialization

1. Resolve and pin the current Git main commit.
2. Read VERSION, VERSION.json, and VERSION_AUTHORITY.md.
3. Load the initiation_call specified by VERSION.json.
4. Follow its prescribed order, including the canonical_entry,
   registered dependencies, admissions, and receipts.
5. Stop on missing evidence, failed verification, or contradictory
   release identity. Never infer authority from README prose.

## Governance

Canonical promotion requires its recorded Human Gate decision.
Documentation does not grant authority, credentials, runtime execution,
or permission to modify originating data.
