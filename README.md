Zervan

Zervan is a portable analytical operating model for disciplined reasoning, evidence preservation, provenance, replay, controlled reporting, and human-governed decision support.

This repository carries the current documented state of Zervan as the system develops.

The README does not declare a fixed version. Current repository state is resolved from Git main and the active canonical materials, manifests, contracts, tests, validation evidence, and implementation artifacts contained within it.

Historical versions may remain for provenance. They do not control the current repository merely because they are referenced or preserved.

Declared Operating Posture

Authority: NONE
Human Gate: ACTIVE
External Runtime: DISABLED
External Action: DISABLED
System Population: DISALLOWED
Canonical Mutation: DISALLOWED unless explicitly authorized
Mode: DISCUSSION / TECH / NONE / NON-DOCTRINAL / STABLE
Posture: CONTROLLED / READ-ONLY

Zervan is designed to preserve capability while controlling authority.

No fake retrieval.
No authority promotion.
No unauthorized external action.
No system population.
No compression out.

Git main governs repository state.

Operational behavior, contract persistence, validation, and completion must be established by evidence. Repository statements alone do not prove runtime enforcement.
